# 牌桌页文字样式表（块 2a，10-28，改进 4）

牌桌页（`table.html`）上的文字分三类（10-29 起“台词”不再单独一类，并进玩家聊天），靠**颜色、字号、粗细**三样区分，一眼就知道是谁说的、是不是牌局本身的信息。以后改页面（块 2b）照这张表来，不要另起一套。

| 类别 | 是什么 | 字号 | 粗细 | 颜色 | 其他 | CSS 类 |
|---|---|---|---|---|---|---|
| 牌桌信息 | 牌局本身的事：一局开始、立直、和了、流局、终局 | 13.5px | 粗 700 | 金色 `--accent` #e9b949 | 左边一道金色竖线 | `.m-table` |
| 系统消息 | 插件说的话：开局、代打、断线、出错、这一桌结束 | 12.5px | 常规 400 | 灰 `--dim` #9fb0a0；代打/断线/出错用橙 `--warn` #f0a05a | 前面一个 `·`，不写名字 | `.m-system`（`.warn`） |
| 玩家聊天 | 玩家说的每一句话：聊天框里打的、`say` 说的、出牌时顺带的（`act` 里的 `say`）都一样 | 15px | 名字粗 700，正文常规 | 名字用**本人的昵称颜色**，正文米白 `--ink` | `名字：正文`；同时在牌桌上本人座位下面冒 12 秒气泡（重连补发的旧聊天不冒） | `.m-chat`、`.bubble` |

规则：
- **昵称在哪儿出现都是粗体加本人颜色**（大厅、座位、聊天、终局、标题）。颜色开局时由 `riichi_open` 定，主人在大厅还能改；开局后锁死。
- 太暗的颜色服务端会往白色里调亮（相对亮度 ≥ 0.28，`lib/room.mjs` 的 `normalizeColor`），在深绿桌布上保证看得清。
- 默认颜色：agent 天蓝 #5ec8f2，主人橙 #ffb454，远端座位淡紫 #c792ea，机器人三种浅灰。
- 名字重了服务端拒收（大厅改名时提示“已经有人用了”）。主人和 agent 同名时，开局工具会把主人的名字后面加“（主人）”。
- 聊天消息的 `kind` 字段由服务端给：`system` / `chat` / `line`；`table` 类由网页自己根据引擎消息生成。网页不区分 `chat` 和 `line`（10-29 主人定：两种长得不一样看着乱），`line` 只留在存档里、给模型看时标“（出牌时）”。

## 牌和桌（块 2b 第一版，10-28）

- 牌面全部用 Canvas 现画（`table.html` 里的 `drawFace` / `tileURL`），画法移植自出视频产线 `频道/产线/web/mahjong.js`：万子“一~九 + 萬”，筒子三色圆，索子竹节（一索是一只孔雀，10-28 晚从“竹子+红点”改的，红点容易看成赤宝牌），字牌用宋体粗字（東南西北發中），白板是蓝框。赤五右上角一个红点。不用任何外部素材，也不用下载。
- 尺寸：手牌 40×58，牌河 26×38，副露和宝牌 22×32，结算卡 28×41。
- 摸切：牌面暗一点；立直宣言牌：横放；被别人鸣走的牌：变淡；副露里被鸣的那张横放，暗杠两头扣着（背面蓝色）。
- 动画：新打出的牌落进牌河（0.35 秒），说话气泡弹出，结算卡淡入；能打的手牌鼠标放上去抬起，立直模式下能立直的牌红框。
- 和了 / 流局弹结算卡：谁和、点谁的炮、亮出的手牌、役（中文）和番数、点数和符番。点一下或 8 秒后收起。

## 轮到谁、特效、音效、结束对局（10-28 晚，主人实测后加）

- **轮到谁**：只看服务端给的 `view.actor`。某一家摸了牌（或吃碰完）要出牌时，他的座位框左边 6px 金线 + 金色描边发光，名字后面一个闪烁的金底小标签“出牌中”（自己是“轮到你出牌”）；下面状态栏写“等 某某 出牌…”。别人打出一张后、下一次摸牌前（可能有人在想要不要吃碰杠和），**谁都不标**，状态栏统一写“等待中…”，所有人看到的一样。自己在鸣牌窗口里时，状态栏写“要鸣牌吗？”（只有自己看得到）。
- 座位名字后面的小灰字“庄”= 这一局的庄家。
- **吃碰杠选项**：按钮文字是“吃 4索，用手里的 3索 5索”；鼠标放到按钮上，手牌里要用的那几张会金框抬起。
- **特效**（`fx()`）：吃、碰、杠、立直、荣和、自摸时，在那一家的座位上弹一个大字（和结算卡同一套宋体粗字、金色、深色描边，外发光用那一家的昵称颜色），外加一圈扩散的光环。立直的字是红色，下面滑进一根千点棒，加一层淡红闪光；荣和、自摸的字更大，下面一行小字写点数和放铳的人，全屏金色闪光、牌桌轻轻一震，大字放完（1.3 秒）再弹结算卡。只在实时消息里放，断线重连补发的牌局记录不放。
- **音效**（`sfx()`）：WebAudio 现场合成，不用任何素材。吃 = 一声牌响 + 两个上行短音；碰 = 两声牌响 + 方波短音；杠 = 三声牌响 + 低音下坠；立直 = 上滑音 + 铃声；荣和 = 低音重击 + 和弦；自摸 = 上行琶音 + 低音。总音量 0.35。浏览器要求先点过页面才出声，所以第一次点击页面时解锁。
- **静音开关**：右上角“🔊 音效 / 🔇 静音”，选择记在浏览器本地（`localStorage` 的 `riichi-mute`），刷新后还在。
- **结束对局**：右上角灰色描边小按钮，只有主人的座位（真人座位）看得到，开局后和大厅里都有；点了先弹确认框（“再想想 / 结束对局”，结束是红色），确认后牌局中止。结束后按钮消失，状态栏写“这一桌结束了（中止）”，聊天还能用。
- **台词**：10-29 起网页上没有单独的台词样式了（`.m-line` 删了）。出牌时顺带的一句和普通聊天显示得一模一样；所有玩家说话都在本人座位下面冒气泡。

## 立直彩蛋音乐（10-28 晚，主人要的梗）

- 别人立直放「别人立直.*」（现在是赵季平《关羽之歌》），自己立直放「自己立直.*」（现在是《雨爱》DJ 版）。旁观时“自己”= 被看的那一家。
- 两首都内置在插件的 `彩蛋/` 目录里，公开发布也带上（主人定的）。想换歌：把新文件改成同样的名字放进 `$DSH_HOME/dsh-riichi/彩蛋/`，这里的优先（mp3 / flac / ogg / m4a / wav 都行），下一桌生效。两处都没有就不放，彩蛋按钮也不显示。
- 立直那一局一直循环放，0.8 秒淡入到音量 0.55；和了或流局时 1.5 秒淡出。自己立直优先：别人的歌在放时自己立直就换成自己的；自己的在放时别人立直不换；同一首在放时再有人立直不重头放。
- 右上角“🎵 彩蛋”单独开关音乐（记在 `localStorage` 的 `riichi-eggs`）；“🔇 静音”也会把它一起关掉。
- 服务端：`GET /room/<码>/egg/other|self?t=座位令牌`（或 `?w=旁观令牌`），支持 Range；`sync` 里的 `eggs` 列出有哪几首。

## BGM、声音面板、小音效（10-28 晚）

- **声音面板**：右上角“🔊 声音”点开：音效（开关 + 音量）、BGM（开关 + 音量）、立直彩蛋（开关，音量跟着音效）、一行写 BGM 是合成的还是放你的文件。都记在浏览器本地：`riichi-mute` / `riichi-sfx-vol`（默认 0.8）/ `riichi-bgm-mute` / `riichi-bgm-vol`（默认 0.5）/ `riichi-eggs`。点面板外面收起。
- **默认就有声音**：进页面先直接试着出声，浏览器放行的话不用点。浏览器拦住时（没跟页面交互过），右上角冒一行小字“点一下页面就有声音”；页面上任何一次点击、按键、触摸（比如大厅里点“准备”）都会解锁，不用专门去点。
- **小音效**：鼠标移到能打的手牌上一声很轻的“嗒”；点吃碰杠和、跳过、立直这些按钮一声短的上滑音；有人打出一张牌一声牌响（自己打的响一点；立直宣言牌只放立直音效，不叠）。
- **合成 BGM（默认）**：WebAudio 现场合成，零体积、没版权问题。雀庄那种轻松氛围：FM 合成的电钢琴（Rhodes）七和弦/九和弦、柔和的正弦+三角波贝斯、很轻的刷子鼓（2、4 拍）和摇摆八分沙锤、F 大调五声音阶的旋律主题。每 4 小节随机换一组和弦进行（6 组，不连着重复），旋律主题按段随机变奏（原样、往上挪、错半拍、稀疏、不唱），鼓有时只剩沙锤或停掉，提前 1.8 秒排好小节所以无缝循环。速度 84。总音量很低（`BGM_SCALE` 0.42 × 音量滑块）。
  - **有人立直**：下一小节起换小调那几组进行（Dm9、A7♭13…），速度 96，沙锤改十六分、底鼓每拍一下、贝斯改八分推着走、旋律基本不唱。
  - **和立直彩蛋的配合**：彩蛋歌在放时 BGM 淡出让位，彩蛋停了再淡入，不会两首一起响。所以“紧张模式”主要在没开彩蛋（或静音了音效）时听得到。
  - **和了、流局**：BGM 歇下来，放一小段收尾（B♭maj9 → Fmaj9 的琶音加贝斯，约 4 秒；彩蛋刚淡出时晚一点放），下一局开始再接上。终局放完收尾就停；中止直接淡出。大厅里也放。
- **自定义 BGM**：`$DSH_HOME/dsh-riichi/bgm/` 里放了 mp3/ogg（flac/m4a/wav 也认），就随机循环放这些（不连着放同一首），不用合成的。服务端按编号给（`GET /room/<码>/bgm/<编号>?t=`，带鉴权，支持 Range），文件开房时定下来，`sync.bgm` 是首数。自定义 BGM 和了流局时不停，彩蛋放时一样让位。插件包里不带任何 BGM 文件。

## 思考中 N 秒（10-28 晚，主人：“你把思考中加进去吧”）

- 某一家摸牌（或吃碰后）要出牌时，他座位上的金色小标签写“思考中 N 秒”（自己是“轮到你出牌 N 秒”），下面状态栏写“等 某某 出牌…（思考中 N 秒）”。不满 1 秒不写秒数（机器人一般一闪而过）。所有座位都这样，不只肥鱼。
- 别人打出一张后的等待（可能有人在想要不要吃碰杠和）：**不标是谁**，状态栏只写所有人都一样的“等待中 N 秒…”（超过 1 秒才出秒数）。
- 计时起点是服务端给的 `view.actorSince` / `view.waitSince`（引擎每发一条消息时记一次，四家共用同一个时间），网页按 `view.now` 校准本机时钟；断线重连时 `sync` 里带着原来的起点，所以接着往上数，不会从 0 开始。只每半秒改这几个小字，不重画牌桌。

## 听牌提示、能和了（10-28 晚，主人实测：“听牌没有提示听的什么牌”“和牌的时候跟出牌界面一样”）

- **听牌提示**：轮到你打牌时，打了就能听牌的手牌底下一个金点；鼠标放到能打的牌上，手牌下面那行写“打 X → 听 [牌] 剩N …”（剩 0 标红），打了不听就写“不听牌”。手里 13 张已经听牌时（等别人打牌那会儿），那行一直写“听 [牌] 剩N …”。听的牌里有自己打过的，后面红字“振听（不能荣和）”。
- “剩几枚”只算你看得到的：自己手牌、四家牌河、副露、宝牌指示牌；别人手里的看不到，所以算在“剩”里。服务端算（`view.hand.ting`、打牌选项的 `ting`），引擎的 `Util.xiangting` / `tingpai`。
- 肥鱼（A 路）和命令行外部座位看到的牌面里也有同样的信息（“你现在听牌：…”“打完听 …”），各家拿到的提示一样。
- **能和了**：能荣和、自摸、抢杠时，下面那行变成红底跳动的“能和了！荣和 X”，和牌按钮放大、红底金边、一直跳；你的座位一圈红光；响一声上行的提示音（一次）。
